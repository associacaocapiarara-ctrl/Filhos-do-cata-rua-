# FILHOS DO CATA RUA

Portal comunitário institucional para a Cooperativa Cata Rua, a Associação dos Moradores e a comunidade de Capiarara.

## Publicação
Este é um primeiro protótipo estático e responsivo. Para publicar no Cloudflare Pages, conecte este repositório GitHub e use:
- Framework preset: None
- Build command: (deixe vazio)
- Build output directory: `/` (ou `.` conforme a interface)

## Importante
A área de moradores ainda é apenas uma apresentação visual. Cadastro, login, solicitações e painel administrativo precisam ser implementados e conectados ao Supabase antes de coletar dados pessoais.
